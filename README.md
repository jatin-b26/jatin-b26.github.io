# jatin-b26.github.io

Public homepage for jatin-b26.github.io.

Google's OAuth consent screen uses this as the app homepage and privacy policy
for Reminder Bot. Same pages as reminder-bot-site, served at the domain root
so Search Console can verify the property.

## What is here

- `index.html` - scroll page: how it works, examples, demo, FAQ, status
- `privacy.html` - privacy policy with the contact address
- `status.json` - heartbeat for the status chip (`state`, `last_ok`)
- `logo.png` - app mark, also used in the consent screen under Branding

## Search Console

`index.html` has the `google-site-verification` meta tag for
`https://jatin-b26.github.io/`. Don't delete it or verification breaks.
